# nibblez

> ascii in love with nibbles 🐍

**nibblez** is a terminal-based ASCII snake game — a modern homage to the classic [Nibbles](https://en.wikipedia.org/wiki/Nibbles_(video_game)) game, rendered entirely in beautiful ASCII art.

---

## Features

- 🎮 Classic snake/nibbles gameplay in your terminal
- 🖼️ Fully ASCII-rendered graphics
- ⌨️ Keyboard controls
- 🏆 Score tracking
- 💀 Progressive difficulty as you grow

## How to Play

| Key | Action |
|-----|--------|
| `↑` / `W` | Move Up |
| `↓` / `S` | Move Down |
| `←` / `A` | Move Left |
| `→` / `D` | Move Right |
| `P` | Pause |
| `Q` | Quit |

Eat the food (`*`) to grow your snake and increase your score. Avoid hitting the walls or your own tail!
