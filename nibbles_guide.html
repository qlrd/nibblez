1 · What is a nibble?

A byte is 8 bits. A nibble is half of that — exactly 4 bits. Because 4 bits can represent values from 0 to 15, one nibble maps perfectly to one hexadecimal digit.

That means every byte splits cleanly into a high nibble (the upper 4 bits) and a low nibble (the lower 4 bits), giving exactly the two hex digits we need to display it.

Byte: 0x42 = 0100 0010 = decimal 66 = ASCII 'B'

2 · High nibble — the >> 4 shift

To isolate the upper 4 bits, we shift the entire byte 4 positions to the right. The lower bits fall off; zeros fill in from the left.

The low nibble bits fell off the right edge. The high nibble slid into the low positions.
Why & 15 after the shift?
When the original char is negative (sign bit set, e.g. ASCII 200), the CPU may fill the left side with 1s instead of 0s during the shift. The mask & 15 cuts those off safely. It costs nothing and prevents wrong nibbles. 
high_nibble = (byte >> 4) & 15;   // e.g. 0x42 → 4

4 · Nibble → hex character

We have a nibble value from 0 to 15. We need to turn it into the right ASCII character ('0'–'9' or 'a'–'f').

NibbleHex digitASCII decimalHow to get there
0 '0'480 + 48 = 48
1 '1'491 + 48 = 49
............
9 '9'579 + 48 = 57
10'a'9710 + 87 = 97  (because 'a'=97, 97−10=87)
11'b'9811 + 87 = 98
12'c'9912 + 87 = 99
13'd'10013 + 87 = 100
14'e'10114 + 87 = 101
15'f'10215 + 87 = 102
 
if (nibble < 10)
    c = nibble + 48;   // '0'–'9'  (ASCII 48–57)
else
    c = nibble + 87;   // 'a'–'f'  (87 = 'a' − 10 = 97 − 10)
Memory trick: '0' is ASCII 48. 'a' is ASCII 97. The gap between them across the 0–9 / a–f boundary: instead of adding 48 to everything and then correcting letters by +49 (awkward), we just switch formula at 10.

7 · ex12 — ft_print_memory walkthrough

This function prints raw memory in three columns per line (16 bytes per line):

Column layout (80 chars per line):

<--- 16-digit address ---><sep><-------- 40-char hex section --------><--- 16-char printable --->

000000010a161f40: 426f 6e6a 6f75 7220 6c65 7320 616d 696e Bonjour les amin

Each pair of bytes shares a space · after the last pair there is also a space (serves as column separator)

Column 1 — 16-digit hex address

A pointer on a 64-bit system is 8 bytes = 64 bits. To print all 16 hex digits we extract nibbles from the most significant down to the least, using a shift that starts at 60 and decreases by 4 each step.

Address: 0x000000010a161f40

shift = 60 → nibble = (addr >> 60) & 15 = 0 → '0'
shift = 56 → nibble = (addr >> 56) & 15 = 0 → '0'
...
shift = 36 → nibble = (addr >> 36) & 15 = 1 → '1'
shift = 32 → nibble = (addr >> 32) & 15 = 0 → '0'
shift = 28 → nibble = (addr >> 28) & 15 = a → 'a'
...
shift = 4 → nibble = (addr >> 4) & 15 = 4 → '4'
shift = 0 → nibble = (addr >> 0) & 15 = 0 → '0'

Result: 000000010a161f40

Column 2 — hex bytes (with padding for short lines)

We loop j = 0..15. For each position: if j < line_len print the two hex chars; otherwise print two spaces. After every pair (when j % 2 == 0) print a space.

Full line (16 bytes): 426f 6e6a 6f75 7220 6c65 7320 616d 696e (40 chars)

Partial line (12 bytes):
0a09 6c6f 6c2e 6c6f 6c0a 2000            
                                ↑ j=12 to 15: " " × 4 + spaces = 10 padding chars

The hex column always occupies exactly 40 characters — guaranteed by the padding logic.

Column 3 — printable characters

Same printable check as ex11 (32–126). Non-printable characters are replaced with a dot '.'.

Full example output

000000010a161f40: 426f 6e6a 6f75 7220 6c65 7320 616d 696e Bonjour les amin
000000010a161f50: 6368 6573 090a 0963 0720 6573 7420 666f ches...c. est fo
000000010a161f90: 0a09 6c6f 6c2e 6c6f 6c0a 2000            ..lol.lol. .

Notice the last line: only 12 bytes of data, so the hex column has 10 spaces of padding before the printable column begins, keeping everything aligned.

Hints for each helper

/* ── address helper ── */
// cast ptr to unsigned long (fits a 64-bit pointer)
// start shift at 60, loop while shift >= 0, step -4  (gives 16 iterations)
// each step: nibble = (val >> shift) & 15  → convert to char → write 1 byte

/* ── hex column helper ── */
// loop j = 0 to 15  (always 16 slots, real data OR padding)
//   if j < len  → read byte, split into 2 nibbles, write 2 hex chars
//   else        → write "  " (two spaces to keep column width)
//   after j++: if j % 2 == 0 → write " " (space every pair of bytes)

/* ── printable column helper ── */
// loop j = 0 to len-1
//   byte >= 32 && byte <= 126  → write the char
//   else                         → write "."
